### 2.1 身份桥接：两个候选（POC 必测其中一个）

**方案 A：网关注入 + HMAC（推荐）**

```
浏览器 --Sa-Token--> Java 网关 --X-User + X-Sign(HMAC-SHA256)--> FastAPI
```

- Java 从 Sa-Token 会话取真实用户，写入 `X-User`、`X-Role`、`X-College`、`X-Timestamp`；
- 签名 = HMAC(secret, user + role + college + timestamp + path)，FastAPI 校验签名与时间窗（±60 s）；
- FastAPI **不再对浏览器发布端口**（去掉 `8010:8000`），只在内网被网关调用。

优点：Python 侧改动最小（一个依赖项 + 去掉 `X-Actor`），且满足「Python 不再直接公开」的要求。

**方案 B：共享 Redis 会话**

FastAPI 直接读 Sa-Token 在 Redis 里的 token → loginId。改动更小，但**耦合 Sa-Token 内部 key 结构**，上游升级可能失效。作为备选。

### 2.2 数据范围：学院 ↔ 部门

框架用 `sys_dept` 树，我们的学院是 `students.college_name` 字符串。

POC 做法：建 6 条 `sys_dept`（对应现有 6 个学院），`campus.students` 与部门不做物理外键，只在查询时把 `dept_id` 映射为 `college_name` 参与过滤。

**若第 6 项验证必须改框架授权层才能成立 → 触发 no-go 条件 4。**
